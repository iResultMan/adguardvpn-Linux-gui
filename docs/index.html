AdGuard VPN
в трее Linux

Окно над консольной программой AdGuard. Состояние, город, пинг и IP обновляются каждые 2 секунды. Подключение в один клик, без терминала.

Открыть репозиторий Как установить Python 3 и PyQt5. Один файл, одна зависимость.

Зачем

У AdGuard VPN нет окна для Linux

Я не хочу помнить команды и держать терминал открытым, чтобы узнать, работает ли VPN. Состояние должно быть видно всегда, как заряд батареи.
автор проекта

На macOS и Windows у AdGuard есть приложения с окном. На Linux производитель даёт только консольную программу adguardvpn-cli: она надёжная, но чтобы увидеть, куда вы подключены, нужно набрать команду. Без VPN работать невозможно, и отвлекаться на проверку каждый раз тоже.

Эта оболочка решает одну задачу: иконка в трее показывает, поднят ли туннель, а окно по клику показывает город, пинг и публичный IP и даёт переключиться на другую локацию.

Что в окне

Всё, что отвечает на вопрос «а VPN сейчас работает?»

Состояние
подключено, отключено или подключается. Иконка в трее меняет цвет вместе с ним.
Город и пинг
к какой локации подключён туннель и с какой задержкой.
Публичный IP
адрес, который видят сайты, и его геолокация. Клик копирует IP в буфер.
Локации
80 с лишним городов с пингами, сортировка по пингу, поиск, избранное. Двойной клик подключает.
Исключения сайтов
список доменов, которые идут мимо VPN (или только через него в режиме SELECTIVE), добавление и удаление.
Аккаунт
вход через браузер, тариф, срок подписки, выход.
Мелочи
автозапуск при входе, русский и английский интерфейс, список локаций из кэша для мгновенного старта.

Устройство

Ничего своего. Только команды производителя

Оболочка не содержит VPN-логики и не трогает сеть. Фоновый поток раз в 2 секунды запускает adguardvpn-cli status и показывает ответ. Каждая кнопка в окне запускает ту же команду, которую вы набрали бы в терминале.

Действие в окнеЧто выполняется
Состояние и город, каждые 2 сadguardvpn-cli status
Аккаунт и тариф, каждые 30 сadguardvpn-cli license
Список локаций и пингиadguardvpn-cli list-locations
Кнопка «Подключиться»adguardvpn-cli connect -y
Двойной клик по локацииadguardvpn-cli connect -l "Город" -y
Кнопка «Отключиться»adguardvpn-cli disconnect
Вход и выходadguardvpn-cli login, adguardvpn-cli logout
Исключения сайтовadguardvpn-cli site-exclusions show / add / remove / clear

Единственное исключение: публичный IP запрашивается по HTTPS у ipwho.is, при сбое у ipapi.co. CLI такой команды не даёт.

Если VPN поднят другим способом, например системным юнитом при загрузке, окно покажет и это: оно читает состояние того же демона, что и CLI.

Установка

Три команды и одно расширение для GNOME

Нужны Linux, Python 3.8 или новее с модулем venv, установленный и авторизованный AdGuard VPN CLI и трей в панели.

  1. Скачать и установить

    git clone https://github.com/iResultMan/adguardvpn-Linux-gui.git
cd adguardvpn-Linux-gui
./install.sh

    Скрипт создаёт venv с PyQt5, ярлык в меню приложений, иконки и автозапуск. Автозапуск потом выключается флажком в окне.

  2. GNOME: включить трей

    В GNOME Shell трея нет. Поставьте расширение AppIndicator: пакет gnome-shell-extension-appindicator в Ubuntu, Debian и Fedora. KDE, Xfce, Cinnamon, MATE и LXQt работают без дополнений.

  3. Запустить

    venv/bin/python AdGuard.py

    Или из меню приложений. Ключ --minimized запускает сразу в трей, так делает автозапуск.

Ограничения

  • Положение окна на Wayland. Wayland не сообщает программам, где их иконка в трее и где курсор. Поэтому окно открывается у правого края панели, там, где живут индикаторы во всех оболочках. На X11 окно встаёт под курсор.
  • Только Linux. На macOS и Windows у AdGuard есть собственные приложения.
  • Первое подключение может попросить настроить права для туннеля. Сделайте это один раз в терминале: adguardvpn-cli connect.
  • Автоподключение до входа в систему делается системным юнитом, пример лежит в systemd/ репозитория. Окно увидит такое подключение как любое другое.
