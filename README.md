# AdGuard VPN GUI для Linux

Значок в трее и окно настроек над официальной консольной программой
`adguardvpn-cli`. Показывает, подключён ли VPN, к какому городу, с каким
пингом и под каким IP. Подключает и отключает в один клик. Ничего не
делает сама: каждая кнопка вызывает ту команду, которую вы набрали бы
в терминале.

[English version](README.en.md)

![Окно настроек AdGuard VPN GUI: подключено к Denver, список локаций с пингами](docs/screenshot.png)

Страница проекта: https://iresultman.github.io/adguardvpn-Linux-gui/

## Зачем

У AdGuard VPN нет графической программы для Linux, только CLI. Я не хочу
помнить команды и держать терминал открытым, чтобы узнать, работает ли VPN.
Без VPN работать невозможно, поэтому его состояние должно быть видно всегда,
как заряд батареи: один значок в трее, одно меню по клику. Так появилась
эта оболочка.

## Из чего состоит

Две программы, каждая делает своё.

**Демон в трее** `adguardvpn-tray`, 2 МБ на диске, 4 МБ в памяти, 0 % CPU.
Написан на Rust, в сеть не ходит, единственное, что делает снаружи, это
запускает `adguardvpn-cli`, `curl` для публичного IP и окно настроек.
Меню по клику на значок, его рисует сама панель:

- Подключено: Denver
- IP 169.150.231.81 · Denver, Colorado, United States
- Подключиться / Отключиться
- Настройки
- Выйти

**Окно настроек** на Python и PyQt5. Открывается пунктом «Настройки» в меню значка или из списка
приложений, закрывается крестиком и после этого не занимает памяти. В нём
всё остальное: крупный статус, 80+ локаций с пингами, поиск и избранное,
исключения сайтов с перетаскиванием файла, вход в аккаунт, автозапуск,
русский и английский язык, установка CLI, если его нет.

## Как это устроено

Ни демон, ни окно не содержат VPN-логики. Оба вызывают `adguardvpn-cli
status` и показывают ответ. Демон делает это без таймера, только по
событиям: CLI создаёт и удаляет `vpn.socket` в своём каталоге, когда служба
стартует и останавливается (inotify), ядро сообщает о появлении туннеля
(netlink), плюс открытие меню и собственные действия. В простое демон не
запускает ничего. Окно, пока открыто, опрашивает раз в 2 секунды. Всё
остальное тоже вызовы CLI:

| Действие | Команда |
|---|---|
| Состояние и город | `adguardvpn-cli status` |
| Аккаунт и тариф (окно, каждые 30 с) | `adguardvpn-cli license` |
| Список локаций и пинги (окно) | `adguardvpn-cli list-locations` |
| «Подключиться» | `adguardvpn-cli connect -y` |
| Двойной клик по локации (окно) | `adguardvpn-cli connect -l "<город>" -y` |
| «Отключиться» | `adguardvpn-cli disconnect` |
| Вход и выход (окно) | `adguardvpn-cli login`, `adguardvpn-cli logout` |
| Исключения сайтов (окно) | `adguardvpn-cli site-exclusions show / add / remove / clear` |

Единственное, что не идёт через CLI, это публичный IP: он запрашивается
у `ipwho.is`, а при сбое у `ipapi.co`. Демон делает это командой `curl`,
окно через HTTPS из Python.

Если VPN поднят другим способом, например systemd-юнитом при загрузке,
значок покажет и это: оба процесса читают состояние того же демона CLI.

## Установка

Нужны: Linux с треем, Python 3.8+ с модулем `venv`, установленный и
авторизованный [AdGuard VPN CLI](https://github.com/AdguardTeam/AdGuardVPNCLI).
Для сборки демона из исходника нужен `cargo`; без него установщик скачает
готовый файл из релиза для x86_64 или aarch64 и сверит контрольную сумму.

```bash
git clone https://github.com/iResultMan/adguardvpn-Linux-gui.git
cd adguardvpn-Linux-gui
./install.sh
```

Скрипт кладёт демон в `bin/`, создаёт `venv` с PyQt5, ярлык окна в меню
приложений и автозапуск демона. Запуск вручную:

```bash
bin/adguardvpn-tray &
venv/bin/python AdGuard.py
```

Если `adguardvpn-cli` не установлен, окно само об этом скажет и покажет
официальную команду установки. Кнопка «Установить в терминале» открывает
терминал с этой командой: вопросы установщика и пароль администратора вы
вводите сами, окно ничего не делает в обход терминала.

**GNOME.** В GNOME Shell трея нет, нужно расширение AppIndicator:
пакет `gnome-shell-extension-appindicator` в Ubuntu, Debian и Fedora.
Без трея демон через минуту откроет окно и завершится.

**KDE, Xfce, Cinnamon, MATE, LXQt** работают без дополнений.

## Справка

| Что | Как |
|---|---|
| Меню демона | левый или правый клик по значку (в KDE левый сразу открывает окно) |
| Открыть окно | пункт меню «Настройки» или ярлык в списке приложений |
| Закрыть окно | `Esc`, крестик или кнопка закрытия в заголовке |
| Выйти из демона | пункт «Выйти» в меню значка |
| Подключиться к локации | двойной клик по строке в окне, либо выделить и нажать «Подключиться» |
| Избранное | правая кнопка мыши по локации в окне |
| Поиск по локациям | кнопка с лупой, `Esc` закрывает поиск |
| Исключения из файла | перетащите текстовый файл со списком доменов в окно исключений |
| Сменить язык | переключатель RU / EN в окне, демон подхватит при следующем изменении статуса |
| Автозапуск | флажок внизу окна, управляет запуском демона |

Файлы программы в домашней папке:

| Файл | Что хранит |
|---|---|
| `~/.config/adguard-gui-settings.json` | язык |
| `~/.config/adguard-gui-favorites.json` | избранные локации |
| `~/.config/adguard-locations-cache.json` | список локаций для мгновенного старта окна |
| `~/.config/autostart/adguard.desktop` | автозапуск демона |
| `$XDG_RUNTIME_DIR/adguardvpn-window.log` | вывод окна, запущенного из меню |

### Автоподключение при загрузке

Необязательно. Если хочется, чтобы VPN поднимался ещё до входа в систему,
в `systemd/adguardvpn.service.example` лежит системный юнит, которым
пользуюсь я. Инструкция внутри файла.

## Доверие

Демон это двоичный файл, и у вас есть три способа убедиться, что в нём:

1. Исходник в `daemon/src/main.rs`, около 500 строк, читается за 15 минут.
2. Файлы в релизах собирает GitHub Actions из этого исходника
   (`.github/workflows/daemon.yml`), рядом лежит `SHA256SUMS`, установщик
   сверяет сумму скачанного файла с ней. Кто не хочет скачивать, собирает
   сам: `cargo build --release --manifest-path daemon/Cargo.toml`, именно
   это делает установщик, когда находит cargo.
3. Демон не открывает сетевых соединений. Проверяется чтением кода: в нём
   нет ни одной сетевой библиотеки.

## Ограничения

- Только Linux. На macOS и Windows у AdGuard есть собственные приложения.
- Подпись с городом рядом со значком в панели пока не выводится, статус
  несут цвет значка, подсказка и первая строка меню.
- Первый `connect` может попросить настроить права (CAP_NET_ADMIN).
  Сделайте это один раз в терминале: `adguardvpn-cli connect`.

## Разработка

```
daemon/           демон в трее на Rust (ksni), один файл
AdGuard.py        окно настроек, один файл
assets/           иконки окна и трея
tests/            тесты парсеров вывода CLI и помощников установки
tools/            установка иконок в тему hicolor
systemd/          пример юнита автоподключения
docs/             страница GitHub Pages
.github/          сборка демона и публикация в релизы
```

Тесты:

```bash
QT_QPA_PLATFORM=offscreen venv/bin/python -m unittest discover -s tests -v
cargo test --manifest-path daemon/Cargo.toml
```

Тесты собраны на реальном выводе AdGuard VPN CLI 1.7.12. Если новая версия
CLI изменит формат, упадут они, а не значок.

Страница проекта публикуется из папки `docs/` ветки `main`.
